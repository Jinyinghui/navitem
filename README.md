# Nav-Item - 现代化个人导航工作台

## 项目简介

一个现代化的个人导航网站项目，采用极光毛玻璃（Glassmorphism）视觉风格与前后端分离架构，提供流畅的多引擎聚合搜索、多级分类书签视图以及清爽的后台管理系统。

## 🛠️ 技术栈
- **前端**：Vue 3 + Vite + 现代响应式 CSS（支持深浅色主题切换、卡片详情/紧凑网格双视图）
- **后端**：Node.js + Express + SQLite + JWT 认证

## ✨ 主要功能

### 前台导航功能
- 🏠 **现代化双视图导航**：支持「详情卡片视图」（展示图标、标题、描述与域名）与「紧凑网格视图」一键切换
- 🌗 **深色极光 / 浅色毛玻璃主题**：内置主题切换并自动记忆偏好
- 🔍 **聚合搜索与全站实时检索**：支持站内跨分类实时过滤，以及 Google、Bing、百度、GitHub、SearXNG 快捷跳转（支持 `/` 快捷键聚焦）
- 📂 **多级栏目胶囊筛选**：支持主分类与二级子分类胶囊标签快速筛选
- 📱 **全端响应式适配**：完美适配桌面端、平板与移动端

### 后台管理功能
- 📊 **概览仪表盘**：直观查看主分类数、子分类数、导航卡片总数及登录安全审计信息
- 📋 **栏目管理**：主菜单和二级子菜单的增删改查与排序
- 🃏 **卡片管理**：导航卡片的增删改查、排序与图标配置
- 👤 **账号安全**：管理员密码修改与登录记录审计

## 🚀 快速启动

```bash
# 1. 安装后端依赖
npm install

# 2. 构建前端
cd web && npm install && npm run build

# 3. 启动服务
cd .. && npm start
```
